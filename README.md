# Store Management System

A Python-based command-line store management application that simulates a shopping experience with authentication, inventory management, billing, discounts, and order confirmation.

## Features

* Admin Login Authentication
* Product Inventory Management
* Product Selection System
* Quantity Selection
* Automatic Bill Calculation
* Discount Application
* Order Summary Generation
* Order Confirmation
* Input Validation

## Technologies Used

* Python
* Dictionaries
* Loops
* Conditional Statements

## How It Works

1. Admin enters the correct password.
2. Customer enters their name.
3. Available products are displayed.
4. Customer selects a product.
5. Customer enters the quantity.
6. The system calculates:

   * Subtotal
   * Discount
   * Final Bill
7. Order summary is displayed.
8. Customer confirms or cancels the order.
